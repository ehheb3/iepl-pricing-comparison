## 为什么 IEPL 年付通常更划算

IEPL（International Ethernet Private Line，国际以太网专线）是国内入口与境外出口之间的一条以太网层专线。Mkcloud 的广港 IEPL 走腾讯广州八线 BGP 入口、香港 BGP 出口，端内 Ping 实测在 1~3ms。同价位 IPLC 延后 20ms+，CN2 GIA 晚高峰可能再往上飘。对延迟敏感的业务（Shopify 后台、海外 SaaS API、跨境支付接口），优先 IEPL。

年付省下来的部分主要来自订单粒度的折扣系数——Mkcloud 公开活动里给出的常规值在 8.5 折左右（约等于 15% off）。活动期内叠加循环码（MK-8.8 等）还能再压一头。备好循环码再下单，比单纯切月付更省事。

## 常见疑问

**Q1：IEPL 年付期间能换套餐大小吗？**
套餐开通后不支持更换地域。同地域内的升降级走工单处理，差价不退。

**Q2：年付中途可以退订或换月付吗？**
仅质量问题可走退款流程，需要在工单里提交延迟数据、测速截图等证据，由 Mkcloud 审核判断。非质量问题不支持退订。

**Q3：Mkcloud 有 SLA 保证吗？**
默认无 SLA 保证。延迟、可用率、持续带宽等细节都建议在工单里或官方联系渠道确认；共享带宽标注的是峰值，不保证持续跑满。

**Q4：年付期间优惠码会变吗？**
循环码（如 MK-8.8、IXCLOUD）在账单周期内默认续期，一直生效。新客码（如 MK-IEPL-WELCOME）通常只对首次购买生效一次。

**Q5：IPLC、IEPL、CN2 GIA 怎么选？**
稳定性 IPLC > IEPL > CN2 GIA，价格反向递减。延迟敏感业务优先 IPLC 或 IEPL；预算敏感的访问型业务可以考虑 CN2 GIA，但要接受晚高峰波动。

**Q6：沪港和广港 IEPL/IPLC 方向哪个好？**
广港 IEPL 价格更低、延迟更小；沪港 IPLC 适合上海本地团队直接接入，延迟约 21ms。按所在地选择即可。
